Using colors to distinguish between local and non-local messages is a great idea! Colors can easily help users visually identify messages based on their origin, improving the user experience.

Suggested Colors:
Local Messages:

Background Color: Light blue or light green (to convey a sense of familiarity or interaction from the current user).

Text Color: Dark or neutral text color (like black or dark gray) for readability.

Non-Local Messages:

Background Color: Light gray or light yellow (indicating a message from someone else).

Text Color: A slightly lighter or faded text color (like dark gray or a muted color).

You can customize the colors based on your design preferences. The key idea is to use contrast to make the local messages stand out from non-local ones while maintaining a cohesive design.

Example Colors:
Local Messages:

Background: #e0f7fa (light cyan)

Text: #00695c (dark teal)

Non-Local Messages:

Background: #f1f1f1 (light gray)

Text: #424242 (dark gray)

Code to Implement:
Here’s an example of how you can implement this logic in the Message component using different colors for local and non-local messages:

tsx
Copy
const Message = ({ message, isCurrentUser }) => {
  // Determine styles based on whether the message is from the current user or not
  const messageStyle = isCurrentUser
    ? "bg-[#e0f7fa] text-[#00695c]" // Local message: light cyan background, dark teal text
    : "bg-[#f1f1f1] text-[#424242]"; // Non-local message: light gray background, dark gray text

  return (
    <div className={`flex items-center space-x-2 p-4 rounded-lg ${messageStyle}`}>
      <div className="message-content">
        {/* Display the original source text */}
        <p>{message.sourceText}</p>
        {/* Display the translated text (if available) */}
        {message.targetText && <p className="text-muted">{message.targetText}</p>}
      </div>
    </div>
  );
};

// Example usage of Message component
const message = {
  id: 1,
  sourceText: "قل هو الله احد الله الصمد لم يلد ولم يولد ولم يكن له كفوا احد",  // Original Arabic text
  targetText: "Say: He is Allah, the One. Allah, the Eternal Refuge. He neither begets nor is born. Nor is there to Him any equivalent.",  // Translated English text
  sourceLang: "ar",  // Source language (Arabic)
  targetLang: "en",  // Target language (English)
  isCurrentUser: true,  // Flag to identify if the message is from the current user
};

// Render the message with different colors based on whether it is from the current user or not
<Message message={message} isCurrentUser={true} />
Explanation of Code:
messageStyle: This variable contains different background and text color classes based on whether the message is from the current user (isCurrentUser is true) or from another user.

Local Messages (isCurrentUser = true): Light cyan background (#e0f7fa) with dark teal text (#00695c).

Non-Local Messages (isCurrentUser = false): Light gray background (#f1f1f1) with dark gray text (#424242).

The className dynamically changes the background and text color based on the isCurrentUser value.

Customization:
Background and Text Colors: You can adjust the colors based on your brand’s color scheme. Use tools like Color Contrast Checker to ensure good readability.

Padding and Borders: You can adjust the padding and border-radius (p-4 and rounded-lg classes in the example) to fit your design.

Font and Text Style: You can modify the font size or style by adding text-lg, font-bold, or any other Tailwind CSS classes to the text or message.
