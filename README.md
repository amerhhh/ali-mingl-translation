# Nauman-Naeem-Translation

A cutting-edge multilingual translation platform that enables real-time, cross-language communication with advanced language detection and adaptive user interfaces.

## Features

- **Real-time Translation**: Speak in your language and get instant translations
- **Bidirectional Communication**: Perfect for conversations between people speaking different languages
- **Specialized Modes**:
  - **Chat Mode**: Interactive with bidirectional translation, displays both source and target languages
  - **Listen Mode**: Passive, focused on target language with UI in target language
- **Technology Options**:
  - **Basic Mode**: Uses Web Speech API for accessibility
  - **Advanced Mode**: Leverages OpenAI's speech recognition for enhanced accuracy
- **Persistent Messages**: Conversations are saved for future reference
- **Mobile-Optimized Design**: Responsive interface works on any device

## Technical Stack

- **Frontend**: React with TypeScript
- **Backend**: Node.js with Express
- **Database**: PostgreSQL for message storage
- **Real-time Communication**: WebSocket technology
- **Speech Processing**: Web Speech API and OpenAI integration
- **Styling**: TailwindCSS with Shadcn UI components

## Getting Started

1. Clone this repository
2. Install dependencies with `npm install`
3. Set up environment variables (see .env.example)
4. Start the development server with `npm run dev`

## Development

This project uses a modern web development workflow:
- TypeScript for type safety
- React for UI rendering
- Express for API endpoints
- Drizzle ORM for database operations
- Vite for fast development and building
